# Лабораторна робота 6

## Чому потрібна функція clearInterval

`setInterval` створює таймер, який повторює перемикання слайдів кожні дві
секунди. Функція очищення `return () => clearInterval(slider)` зупиняє
попередній таймер перед повторним запуском ефекту та під час видалення
компонента зі сторінки. Без очищення накопичувалися б таймери, які
одночасно змінювали б слайд, а після видалення компонента продовжували б працювати.

## Чому index передається в масиві залежностей useEffect

Функція всередині таймера використовує значення `index` із того рендеру,
під час якого створено ефект. Залежність `index` запускає ефект заново
після зміни поточного слайда: попередній таймер зупиняється, а новий
отримує актуальний індекс. З порожнім масивом залежностей таймер
постійно використовував би початкове значення `index`.

У коді також вказано `people.length`, оскільки таймер використовує
кількість слайдів для переходу з першого слайда на останній.
